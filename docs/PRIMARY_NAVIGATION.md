# Primary Navigation

Teret Bet uses three persistent destinations:

- Discover: full visual library, Continue Reading, Recently Read, search, and
  filters.
- Favourites: the same accessible library tools scoped to saved stories.
- Settings: language and reader text-size controls inside the primary shell.

Favourites is a destination scope rather than a removable refinement. Clearing
search, collection, age, or theme filters while viewing Favourites therefore
keeps the library limited to favourite stories. Moving back to Discover removes
that scope while retaining ordinary discovery refinements until the family
clears them.

The navigation bar uses selected and unselected Material icons, bilingual
labels, and standard touch targets. Story details and the reader remain pushed
routes so Android back navigation returns to the originating destination.

Widget coverage verifies destination selection, favourites scoping, embedded
Settings, and persistence of the navigation shell.
