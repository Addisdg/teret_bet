# Pilot Text Drafts

These files are review artifacts, not live catalogue content. They contain no
final images and are not referenced by `story_manifest.json`.

Review each page for:

- natural spoken Amharic;
- natural complete English;
- matching meaning and emotional beat across languages;
- age 3-6 safety;
- continuity and unhurried pacing;
- whether a page should be split, joined, moved, or expanded.

There is no fixed page target or upper limit. Illustration beats are planning
notes only; images begin after explicit text lock and illustration-plan approval.
